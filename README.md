# Blackford Rovers PWA v8

Adds squad management to the admin panel:
- Add players with name, nationality, position, rating, height and optional image path/URL.
- Remove players after transfers.
- Player roster is persisted in data/club-data.json.
- Existing squad is migrated into the persistent player data automatically.
